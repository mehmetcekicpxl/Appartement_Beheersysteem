# Appartement Beheersysteem

Een mobiele applicatie voor het efficiënt beheren van appartementencomplexen, inclusief het bijhouden van bewoners en betalingen.

## Functionaliteiten
* Overzicht van alle appartementen.
* Registratie van betalingen en achterstanden.
* Ontwikkeld voor Android.

## Installatie
Open dit project in Android Studio en bouw de APK.
